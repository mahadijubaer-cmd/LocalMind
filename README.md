# LocalMind

LocalMind is a local-first, auditable project-memory service for preserving,
reviewing, retrieving, correcting, and deleting source-linked project context
across supported AI clients.

The project is specification-first. The complete and sole canonical product
specification begins at [spec/README.md](spec/README.md). Implementation,
tests, issues, and documentation must cite its stable requirement IDs.

Development follows the mandatory
[spec-first process](spec/18-development-process.md) and
[sequential sprint plan](spec/19-sprint-plan.md).

`LocalMind_Blueprint.md` is retained as non-normative historical input.
